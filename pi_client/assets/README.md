# assets

Pi 클라이언트가 쓰는 소리 파일을 두는 폴더입니다.

| 파일 | 내용 |
| --- | --- |
| `ask_status.wav` | 낙상 의심 때 스피커로 재생하는 안내 음성. 예: "괜찮으세요? 괜찮으시면 '괜찮아요'라고 말씀해 주세요." |

- 형식: WAV, 16비트, **16 kHz 모노 권장**(녹음과 같은 형식이라 장치 설정이 꼬이지 않습니다). 길이는 3~5초.
- 다른 위치의 파일을 쓰려면 `pi-client.env`에 `PI_PROMPT_WAV=/경로/파일.wav`를 넣습니다.
- 파일이 없거나 재생에 실패해도 음성 확인은 계속됩니다(경고 로그를 남기고 바로 녹음합니다. 현장 화면에 안내 문구가 나옵니다).
- **wav 파일은 저장소에 올리지 않습니다.** 팀 공유 드라이브에서 받아 이 폴더에 넣거나 아래처럼 직접 만듭니다.

만드는 방법은 [README.md](../../README.md)의 "안내 음성 만들기"를 보세요.
